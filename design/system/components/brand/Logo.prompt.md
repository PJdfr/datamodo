One-line: The datamodo wordmark — "data" handwritten (Caveat) flowing into "modo" in display type; use it anywhere the brand mark appears.

```jsx
<Logo />
<Logo dataSize={26} modoSize={19} onDark />
```

Variants: `dataSize`/`modoSize` scale the two halves independently (keep the ~1.4× ratio). `onDark` swaps ink for cream on dark sections. Never substitute an image or icon — the mark is always live text.
