One-line: The datamodo action button — solid coral for the main CTA, ink pill for nav, tan outline / ghost for secondary.

```jsx
<Button>Get your inbox — free</Button>
<Button variant="dark" size="sm">Get started</Button>
<Button variant="outline">See it in action</Button>
```

Variants: `primary` (coral, warm shadow), `dark` (ink fill, cream text), `outline` (tan hairline), `ghost`. Sizes `sm`/`md`/`lg`. Use `as="a"` + `href` for link buttons. Set `onDark` when an outline/ghost sits on an ink section.
